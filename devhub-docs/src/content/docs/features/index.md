DevHub is the project workspace for engineering teams: tasks, bugs, tests, schema, decisions, and releases — tracked in one place, readable by your AI tools.

Every package includes every feature. The free plan covers up to 2 members and 3 projects — see [Billing & Pricing](/billing/).

## Plan the work

- [Tasks & board](/features/tasks/) — Kanban (Todo / In Progress / Review / Done), milestone and calendar views, dependencies, due dates.
- [Issues](/features/issues/) — severity, lifecycle, reproduction steps, linked fixing tasks.

## Record the why

- [Decisions (ADRs)](/features/decisions/) — context, options, consequences; searchable long after the meeting.
- [Database schema](/features/schema/) — tables, columns, relations, visual ERD, versioning and diffs.
- [API docs](/features/api-docs/) — collections and endpoints with headers, params, body, responses, OpenAPI import/export.

## Ship the release

- [Milestones & releases](/features/milestones/) — target dates, changelogs, per-milestone task lists.
- [Test cases](/features/testing/) — Pass / Fail / Pending checklists attached to tasks and issues.
- [Whiteboards](/features/whiteboard/) — sketch ideas on a canvas; the keepers become tasks.

## Work with AI agents

- [MCP integration](/mcp/) — OAuth 2.1 PKCE and 25 tools so opencode, Claude Code, or Cursor read and update project state directly.
- [Project integrations](/integrations/) — Google Calendar and GitHub, connected per project.
