API docs your team can read. Collections and endpoints documented and searchable, with a read-only docs preview.

## What you document

Per endpoint: HTTP method, path, description, headers, params (path / query / header), request body, and example responses.

## OpenAPI

Import and export OpenAPI 3.0.3 (YAML/JSON) so the inventory stays in sync with the implementation.

## Working with agents

MCP tools: `add_api_collection`, `add_api_endpoint`, `update_api_endpoint`. If a feature exposes HTTP endpoints, document them right after the route is committed — before marking the task done. See [MCP Integration](/mcp/).
