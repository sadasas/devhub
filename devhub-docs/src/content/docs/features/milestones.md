Cut a release with a changelog. Milestones bundle finished work into versions worth announcing.

## What you get

- **Target dates** and status flow: `planned → inProgress → released`.
- **Changelog** attached to every milestone.
- **Per-milestone task lists** in the release detail view, plus estimates vs actuals and velocity in Stats.

## Working with agents

MCP tools: `add_milestone` / `update_milestone` (name, status, version, targetDate, changelog). See [MCP Integration](/mcp/) for auth and the full tool list.
