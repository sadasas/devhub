Dari sticky note menjadi tugas. Sketsa ide di whiteboard; yang layak menjadi tugas — seperti checklist onboarding.

## Kanvas

Sticky, shape, edge, boundary, teks, stroke, dan kartu ref entitas live, plus ekspor ke PNG/SVG/PDF.

## Wireframe AI

Elemen `embed` menampung wireframe SVG buatan AI (allowlist sanitasi, maks 20 per papan). Edit granular via `patch_whiteboard`, dengan cek dry-run `validate_whiteboard` sebelum menulis.

## Bekerja dengan agen

MCP tools: `create_whiteboard`, `update_whiteboard`, `patch_whiteboard`, `validate_whiteboard`, `list_whiteboards`. Lihat [Integrasi MCP](/id/mcp/) untuk auth dan daftar tool lengkap.
