Selesai berarti teruji. Checklist test case menempel pada tugas dan isu, masing-masing dengan langkah, hasil yang diharapkan, dan status: Lulus, Gagal, atau Pending.

## Yang didapat

- Checklist per tugas atau isu — langkah verifikasi plus hasil yang diharapkan.
- Status sekilas seluruh proyek, sehingga "selesai" selalu berarti "teruji".

## Bekerja dengan agen

MCP tools: `add_test_case` / `update_test_case` (name, taskId / issueId, steps, expected, status). Tulis test case saat tugas atau isu dibuat, ubah jadi lulus saat perbaikan mendarat. Lihat [Integrasi MCP](/id/mcp/).

Bagian dari [Fitur](/id/features/). Terkait: [Tugas](/id/features/tasks/) dan [Isu](/id/features/issues/) yang diverifikasi test case, [Milestone](/id/features/milestones/) yang merilisnya.
