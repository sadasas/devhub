DevHub adalah workspace proyek untuk tim engineering: tugas, bug, tes, skema, keputusan, dan rilis — terlacak di satu tempat, terbaca oleh AI tools Anda.

Setiap paket mencakup semua fitur. Paket gratis mencakup hingga 2 member dan 3 proyek — lihat [Billing & Harga](/id/billing/).

## Rencanakan pekerjaan

- [Tugas & papan](/id/features/tasks/) — Kanban (Todo / In Progress / Review / Done), tampilan milestone dan kalender, dependensi, tenggat.
- [Isu](/id/features/issues/) — severity, lifecycle, langkah reproduksi, tugas perbaikan tertaut.

## Catat alasannya

- [Keputusan (ADR)](/id/features/decisions/) — konteks, opsi, konsekuensi; tetap searchable lama setelah meeting.
- [Skema database](/id/features/schema/) — tabel, kolom, relasi, ERD visual, versioning dan diff.
- [Dokumentasi API](/id/features/api-docs/) — collection dan endpoint dengan header, param, body, respons, impor/ekspor OpenAPI.

## Kirim rilisnya

- [Milestone & rilis](/id/features/milestones/) — target tanggal, changelog, daftar tugas per milestone.
- [Test case](/id/features/testing/) — checklist Lulus / Gagal / Pending yang menempel pada tugas dan isu.
- [Whiteboard](/id/features/whiteboard/) — sketsa ide di kanvas; yang layak jadi tugas.

## Bekerja dengan agen AI

- [Integrasi MCP](/id/mcp/) — OAuth 2.1 PKCE dan 25 tools agar opencode, Claude Code, atau Cursor membaca dan mengubah state proyek langsung.
- [Integrasi proyek](/id/integrations/) — Google Calendar dan GitHub, dihubungkan per proyek.
