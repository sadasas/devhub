Everything you need to know about DevHub

DevHub is a hosted SaaS project management application designed specifically for engineering teams. It combines lightweight task/issue tracking with developer-specific modules — tech stack ledger, database schema + ERD, ADR decision log, test cases, and velocity stats — into one hosted application.

DevHub is the complementary technical-memory layer to Jira/Linear. While those tools focus on general project management, DevHub captures the technical context that's often lost: database schemas, architecture decisions (ADRs), tech stack dependencies, and technical debt tracking.

DevHub is a hosted SaaS application only. Self-hosting is not supported in V1. We guarantee data portability via JSON export/import, so your data is never locked in.

Yes! DevHub is designed with AI agents in mind. Our MCP (Model Communication Protocol) integration allows AI agents like opencode, Claude, and others to read project state, create tasks, update status, and help build faster with complete technical context.

When you export, you get a complete JSON backup of your project including all tasks, issues, test cases, tech stack entries, schema definitions, and decisions. You can import this JSON to restore your project or move to another instance.
