## Sisa pekerjaan / catatan

- **Rewrite git history** sebelum repo di-push (3 key historis di 6 commit — sudah dirotasi/mati, prioritas rendah karena tidak ada remote).
- **Test infra**: 2 test app flaky pra-ada (ChatPanel/IndexedDB timing) — lolos di isolasi; CI paralel bisa kena. Bukan bagian audit ini.
- **`as never as` casts di mcp/server.ts** — hygiene TypeScript, dipertahankan (signature SDK stabil).
- **Cluster merge activity** (jendela 60s, baca-lalu-tulis tanpa lock) — race kecil, dicatat.
- **jsonb_set partial update / ekstraksi entity besar** — keputusan arsitektur jangka panjang, tidak dieksekusi sekarang (ADR-002).
