# DevHub Landing Page — SEO Keyword Research

**Document Version:** 1.0  
**Created:** 2026-09-03  
**Target:** Engineering teams (2–2,000 developers)  
**Competitors:** Linear, Jira, GitHub Projects, Plane  

---

## Executive Summary

DevHub occupies a unique position: **project management + technical memory**. This research targets the intersection of PM tool keywords (high volume, competitive) and developer documentation keywords (lower volume, higher intent, less competitive).

**Strategy:**  
- **Primary keywords** for homepage/hero (brand awareness, top-of-funnel)  
- **Long-tail keywords** for feature pages (high intent, conversion-ready)  
- **Question keywords** for FAQ/blog (informational, builds authority)  
- **Commercial keywords** for pricing/CTA sections (transactional, bottom-of-funnel)  

**Key Insight:** DevHub should NOT compete head-on with "project management software" (KD 85–90). Instead, own the niche: **"technical documentation for engineering teams"** (KD 35–50) while capturing PM traffic via long-tail modifiers ("for developers", "for software teams").

## 10. Keyword Cannibalization Prevention

**CRITICAL:** Before publishing any page, verify no two pages target the same primary keyword.

### 10.1 Keyword Ownership Map

| Primary Keyword | Owner Page | Do Not Target On |
|-----------------|------------|------------------|
| `project management for developers` | Homepage | Feature pages, Blog (use modifiers) |
| `database schema documentation tool` | `/features/schema` | Homepage (use as secondary), Blog |
| `architecture decision record template` | `/features/adr` | Homepage, Other features |
| `tech stack tracker for teams` | `/features/tech-stack` | Homepage, Other features |
| `test case management for developers` | `/features/test-cases` | Homepage (secondary only) |
| `issue tracking for software teams` | `/features/issues` | Homepage (secondary only) |
| `project management software free trial` | `/pricing` | Homepage (CTA only, not page target) |

### 10.2 Pre-Publish Checklist

Before publishing any new page or blog post:

- [ ] Search existing pages for target primary keyword in title/H1
- [ ] Verify no other page has higher authority on the keyword
- [ ] If keyword is already owned, use long-tail modifier instead
- [ ] Add internal link FROM existing page TO new page (consolidate authority)
- [ ] Update sitemap.xml
- [ ] Submit to Google Search Console (once access is granted)
